Quy trình cấp phát IP động: DHCP DORA (4 Bước)

Bấm nút "Gửi gói tin" tại từng bước để xem cấu trúc bản tin Wireshark mô phỏng tương ứng:

BƯỚC 1 · CLIENT → LAN
DHCP Discover
Client phát sóng broadcast (255.255.255.255) tìm kiếm máy chủ DHCP.
BƯỚC 2 · SERVER → CLIENT
DHCP Offer
Server đề xuất địa chỉ IP, Subnet Mask và Gateway cho Client.
BƯỚC 3 · CLIENT → SERVER
DHCP Request
Client broadcast xác nhận đồng ý nhận dải IP từ server chỉ định.
BƯỚC 4 · SERVER → CLIENT
DHCP ACK
Server xác nhận chốt hợp đồng thuê (Lease) và hoàn tất cấu hình.
